# SumanCare

SumanCare is an AI-powered health monitoring and early-risk insight platform designed to help patients understand their changing health patterns.

## Domain
Healthcare & Wellness

## Core Idea
SumanCare combines health and lifestyle data with AI/ML to identify changing health patterns and provide explainable, actionable insights.

## Project Structure

- frontend/ - Patient-facing web application
- backend/ - API and application logic
- database/ - Database schema and data
- ai_ml/ - Data analysis and machine learning
- docs/ - Project documentation
